# Кодове королівство

Гра-квест з інформатики для 7–9 класів. Працює в браузері, можна встановити як застосунок (кнопка «Встановити гру» на першій сторінці в Chrome чи Edge). Після першого відкриття гра завантажує всі файли й далі працює без інтернету.

Прототип: прогрес і класи зберігаються лише в браузері пристрою (localStorage), сервера ще немає.

Відкривати лише через http(s), не як файл з диска.
